## Other refusals

| Status | What to look at                                                                  |
| ------ | -------------------------------------------------------------------------------- |
| `404`  | The path is not the one `resourceServerUrl` names. The error says which is       |
| `400`  | Routing headers are missing, or `Mcp-Method` / `Mcp-Name` disagree with the body |
| `413`  | The JSON-RPC body is over `maxRequestBytes` (1 MiB by default)                   |
| `415`  | The POST content type is not JSON                                                |

Boot-time failures come with their own message. A capability no role can reach
throws and names it; see [Boot-time checks](/mcp-authz/concepts/reconciliation/).

## Asking the policy why

Somebody surprised by what they can or cannot do needs the rule, not the
outcome. `policy.explain` and `npx mcp-authz explain` both point at the rule
index an administrator edits, without a server running. See [the CLI](/mcp-authz/typescript/cli/).
